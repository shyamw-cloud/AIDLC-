# AI SDLC framework acceptance checklist

- [ ] Jira issue can be fetched via MCP
- [ ] The issue is normalized into a structured ticket model
- [ ] The spec includes scope, acceptance criteria, risks, and non-goals
- [ ] The task plan includes validation checkpoints
- [ ] Code generation occurs after spec creation
- [ ] Tests are executed before PR creation
- [ ] PR description is linked to the issue
- [ ] Jira status is updated after implementation
